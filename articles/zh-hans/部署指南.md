# Django 博客部署指南：从零到自动更新

> 适用项目：myblog_Django (Django 6.0 + Python 3.13)

---

## 一、我们要做什么

### 目标

把一个本地写好的 Django 博客项目，放到公网上让别人能访问。并且每次在 GitHub 上更新代码后，网站能自动更新。

### 拆解目标

```
最终目标：网站上线 + 自动更新
 ├─ 第一步：把代码放到 GitHub（代码托管）
 ├─ 第二步：在 PythonAnywhere 上创建网站（服务器）
 ├─ 第三步：配置 GitHub Actions 自动部署（自动更新）
 └─ 完成
```

---

## 二、需要什么（以及它们是什么）

### 1. 一个制作完成的 Django 博客项目

就是你正在开发的 Django 博客项目，包含文章、评论、用户等功能。

> 如果还没有项目，可以参考我之前写的 Django 博客教程：\[链接地址\]

### 2. GitHub —— 代码存放的地方

![](images/github-logo-placeholder.png)

- **是什么**：代码托管平台，相当于你的代码在云端的备份
- **用来做什么**：存放项目代码，记录每次修改历史
- **需要什么**：一个 GitHub 账号（免费）

### 3. PythonAnywhere —— 网站运行的地方

![](images/pythonanywhere-logo-placeholder.png)

- **是什么**：云端服务器，专门用来运行 Python 网站
- **用来做什么**：让你的 Django 项目 24 小时在线运行
- **需要什么**：一个 PythonAnywhere 账号（免费版足够）

### 4. GitHub Actions —— 自动部署的工具

![](images/github-actions-placeholder.png)

- **是什么**：GitHub 自带的自动化工具
- **用来做什么**：当你把代码推送到 GitHub 时，自动通知 PythonAnywhere 更新网站
- **需要什么**：GitHub 账号自带，无需额外付费

## 三、准备工作

### 检查你的项目结构

确保项目根目录下有以下关键文件：

```
myblog_Django/
├── manage.py              # Django 管理脚本
├── requirements.txt        # Python 依赖清单
├── myblog/
│   ├── settings.py         # Django 配置文件
│   ├── wsgi.py             # 网站入口文件
│   └── urls.py             # URL 路由
├── blog/                   # 博客应用
├── users/                  # 用户应用
├── comments/               # 评论应用
└── .github/workflows/      # GitHub Actions 配置（自动部署用）
```

> 如果没有 `requirements.txt` 文件，在本地终端运行：
> ```bash
> pip install django django-ckeditor-5 pillow gunicorn whitenoise
> pip freeze > requirements.txt
> ```

## 四、第一步：把代码上传到 GitHub

### 4.1 在 GitHub 上创建仓库

1. 登录 [github.com](https://github.com)
2. 点击右上角 **+ → New repository**
3. 仓库名填 `myblog_Django`，选择 **Public**
4. 不要勾选任何选项，直接点击 **Create repository**

![](images/create-repo-placeholder.png)

### 4.2 本地代码推送到 GitHub

在本地电脑的终端中（项目目录下），按顺序执行：

```bash
# 初始化 Git（如果还没初始化）
git init

# 添加所有文件到 Git
git add .

# 提交
git commit -m "first commit"

# 关联远程仓库（替换成你自己的 GitHub 用户名）
git remote add origin https://github.com/你的用户名/myblog_Django.git

# 推送到 GitHub
git push -u origin main
```

> 如果默认分支是 `master` 而不是 `main`，用 `master` 替换上面的 `main`。
> 如果之前已经提交过，直接执行 `git push` 即可。

## 五、第二步：在 PythonAnywhere 上部署网站

### 5.1 注册并登录

1. 打开 [pythonanywhere.com](https://www.pythonanywhere.com)
2. 注册一个账号（免费版即可）
3. 注册后你会得到一个域名：`你的用户名.pythonanywhere.com`

![](images/pa-signup-placeholder.png)

### 5.2 打开 Bash 控制台

登录后，点击顶部菜单 **Consoles → Bash**，打开一个命令行窗口。

![](images/pa-console-placeholder.png)

### 5.3 克隆代码并安装依赖

在打开的 Bash 命令行中，逐条执行以下命令：

```bash
# 从 GitHub 克隆项目
git clone -b main https://github.com/你的用户名/myblog_Django.git

# 进入项目目录
cd myblog_Django

# 创建虚拟环境（隔离的 Python 运行环境）
python3 -m venv venv

# 激活虚拟环境
source venv/bin/activate

# 安装所有依赖
pip install -r requirements.txt
```

### 5.4 准备静态文件和数据库

继续在 Bash 中执行：

```bash
# 收集所有静态文件（CSS、JS、图片等）
python manage.py collectstatic --noinput

# 创建数据库表
python manage.py migrate

# 创建管理员账号（按提示输入用户名、邮箱、密码）
python manage.py createsuperuser
```

### 5.5 配置 Web 应用

点击顶部菜单 **Web**，进入 Web 应用管理页面。

![](images/pa-web-page-placeholder.png)

点击 **Add a new web app**，然后：

1. 点击 **Manual Configuration**（手动配置）
2. 选择 **Python 3.12**
3. 点击 **Next** 完成创建

### 5.6 填写配置信息

创建完成后，在 Web 页面找到以下设置项并修改：

| 设置项 | 填写内容 |
|--------|----------|
| **Code**（源代码目录） | `/home/你的用户名/myblog_Django` |
| **Working directory**（工作目录） | `/home/你的用户名/myblog_Django` |
| **Virtualenv**（虚拟环境） | `/home/你的用户名/myblog_Django/venv` |

![](images/pa-settings-placeholder.png)

### 5.7 修改 WSGI 文件

在 Web 页面找到 **WSGI configuration file**，点击链接进入编辑页面。

**把文件里所有内容删除**，替换为以下代码：

```python
import os
import sys

# 项目路径
path = '/home/你的用户名/myblog_Django'
if path not in sys.path:
    sys.path.append(path)

# 指定 Django 的配置文件
os.environ['DJANGO_SETTINGS_MODULE'] = 'myblog.settings'

# 生产环境关闭调试模式
os.environ['DJANGO_DEBUG'] = 'False'

# 启动 Django
from django.core.wsgi import get_wsgi_application
application = get_wsgi_application()
```

> **注意**：把 `你的用户名` 替换成你的实际用户名，比如 `EthanBAI`。

点击 **Save** 保存。

### 5.8 添加静态文件映射

在同一页面向下滚动，找到 **Static files** 部分：

![](images/pa-static-files-placeholder.png)

添加两条记录：

| URL | Directory |
|-----|-----------|
| `/static/` | `/home/你的用户名/myblog_Django/staticfiles` |
| `/media/` | `/home/你的用户名/myblog_Django/media` |

### 5.9 重载网站

点击页面顶部的绿色 **Reload** 按钮。

![](images/pa-reload-placeholder.png)

### 5.10 访问你的网站

打开浏览器，访问：

```
https://你的用户名.pythonanywhere.com
```

如果一切正常，你的博客应该已经上线了！

## 六、第三步：配置自动部署

每次更新代码后都要手动登录 PythonAnywhere 太麻烦。下面配置 **GitHub Actions** 实现自动部署。

### 6.1 在 PythonAnywhere 创建部署脚本

回到 PythonAnywhere 的 **Bash Console**，执行：

```bash
cd ~
nano deploy.sh
```

粘贴以下内容：

```bash
#!/bin/bash
# 自动部署脚本 —— 拉取最新代码、更新依赖、迁移数据库
cd /home/你的用户名/myblog_Django

# 从 GitHub 拉取最新代码
git pull origin main

# 激活虚拟环境
source venv/bin/activate

# 更新依赖
pip install -r requirements.txt -q

# 运行数据库迁移
python manage.py migrate --noinput

# 收集静态文件
python manage.py collectstatic --noinput

echo "代码已更新完成！"
```

> **注意**：把 `你的用户名` 替换成你的实际用户名。

按 `Ctrl+X`，然后按 `Y`，再按 `Enter` 保存。

然后执行：

```bash
chmod +x deploy.sh
```

### 6.2 创建定时任务作为保底（可选）

PythonAnywhere 的定时任务是付费功能，如果不想付费可以跳过这一步。后续全靠 GitHub Actions。

### 6.3 在 GitHub 仓库添加 Secrets

Secrets 是加密的敏感信息，GitHub Actions 需要用它们来连接 PythonAnywhere。

#### Step 1：生成 PythonAnywhere API Token

1. 登录 PythonAnywhere
2. 点击右上角头像 → **Account**
3. 点击 **API Token** 标签
4. 点击 **Create new API token**
5. 复制生成的 token（一串长字符串）

![](images/pa-api-token-placeholder.png)

#### Step 2：在 GitHub 中添加 Secrets

1. 打开你的 GitHub 仓库：`https://github.com/你的用户名/myblog_Django`
2. 点击 **Settings** 标签
3. 左侧菜单找到 **Secrets and variables → Actions**

![](images/github-secrets-placeholder.png)

4. 点击 **New repository secret**，添加两个 secret：

| Name | Value |
|------|-------|
| `PA_API_TOKEN` | 上一步从 PythonAnywhere 复制的 token |
| `PA_USERNAME` | 你的 PythonAnywhere 用户名（比如 `EthanBAI`） |

### 6.4 GitHub Actions 配置说明

项目中的 `.github/workflows/deploy.yml` 文件已经配置好了自动部署流程。它的工作流程如下：

```
你 push 代码到 GitHub
      ↓
GitHub Actions 被触发
      ↓
通过 API 通知 PythonAnywhere
      ↓
PythonAnywhere 执行部署脚本
（拉取代码 → 安装依赖 → 迁移数据库 → 收集静态文件）
      ↓
网站自动更新完成 🎉
```

配置文件内容如下（一般不需要修改）：

```yaml
name: Deploy to PythonAnywhere

on:
  push:
    branches: [main]          # 当 main 分支有推送时触发

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - name: 触发 PythonAnywhere 部署
        run: |
          curl -H "Authorization: Token ${{ secrets.PA_API_TOKEN }}" \
               -H "Content-Type: application/json" \
               -X POST \
               "https://www.pythonanywhere.com/api/v0/user/${{ secrets.PA_USERNAME }}/webapps/${{ secrets.PA_USERNAME }}.pythonanywhere.com/reload/"
```

### 6.5 测试自动部署

1. 在本地项目中修改任意内容（比如改个页面文字）
2. 提交并推送：

```bash
git add .
git commit -m "测试自动部署"
git push origin main
```

3. 打开 GitHub 仓库 → **Actions** 标签页，可以看到正在运行的工作流

![](images/github-actions-running-placeholder.png)

4. 等待工作流变成绿色勾（约 30 秒）
5. 刷新你的网站，看到修改已经生效

## 七、常见问题

### Q：网站显示 502 Bad Gateway

**原因**：WSGI 配置有问题或依赖没装全。

**解决**：
1. 点击 PythonAnywhere Web 页面的 **Error log** 查看错误日志
2. 常见原因：`settings.py` 中 `DEBUG = False` 但没有配置 `ALLOWED_HOSTS`
3. 在 `settings.py` 中添加：`ALLOWED_HOSTS = ['你的用户名.pythonanywhere.com', 'localhost']`

### Q：静态文件不显示（没有 CSS、图片）

**原因**：静态文件路径没配置对。

**解决**：检查 Web 页面的 Static files 配置是否正确：
- `/static/` → `/home/你的用户名/myblog_Django/staticfiles`
- 然后重新运行 `python manage.py collectstatic`

### Q：数据库错误

**原因**：数据库迁移没执行。

**解决**：在 Bash 中运行 `python manage.py migrate`

### Q：GitHub Actions 运行失败

**原因**：Secrets 配置错误或网络问题。

**解决**：
1. 检查 GitHub 仓库 Settings → Secrets 中 `PA_API_TOKEN` 和 `PA_USERNAME` 是否正确
2. 在 PythonAnywhere Account → API Token 页面确认 token 有效
