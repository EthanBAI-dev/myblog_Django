MY STORY

每一段经历，都是代码的一部分。

从最初的好奇到如今的专注，这是一段关于成长、坚持与热爱的旅程。

成长轨迹

2025 — 至今

深度学习专项学习

系统性地学习 Andrew Ng 深度学习五门课程，涵盖神经网络基础、超参数调优、结构化机器学习、CNN、RNN 与注意力机制等核心领域。完成所有课程的笔记整理与代码实践，构建个人 AI 知识体系。

2024 — 2025

Web 开发与全栈探索

深入学习 Django 框架，从后端 API 设计到前端模板渲染，掌握了完整的 Web 开发流程。搭建个人博客系统，将学习过程中的思考与笔记沉淀为结构化的知识输出。

2023 — 2024

Python 与数据科学入门

从 Python 基础语法开始，逐步深入到 NumPy、Pandas、Matplotlib 等数据科学生态工具。建立扎实的编程基础，为后续的 AI 学习奠定了坚实的技术根基。

更早之前

对技术的原始好奇

对计算机科学的兴趣始于对"机器如何思考"这一问题的好奇。从第一行 Hello World 到如今能够训练神经网络模型，每一步都是对未知世界的探索。

关于坚持

"学习 AI 不是一场短跑，而是一场没有终点的马拉松。重要的是每天都比昨天多理解一点点。"

坚持做深度学习笔记整理这件事，已经成为了我日常生活的一部分。起初只是为了记录课程中的关键概念，但随着笔记越积越多，我发现这个过程本身比学习课程更有价值。写笔记不是简单的摘抄，而是强迫自己用最清晰的语言重新组织知识，在反复的推敲和修改中，很多曾经模糊的概念突然变得清晰起来。

在这个过程中，我深刻体会到：真正的学习不是"听过"或"看过"，而是能够用自己的语言重新表达，并且能够将不同领域的知识连接起来。深度学习的美妙之处在于，它不是一个孤立的学科——它连接着数学、统计学、计算机科学和认知科学，每一次学习都像是在拼图中加入新的一块。

最让我感到满足的时刻，不是完成某门课程，也不是跑通了某个模型，而是在某个深夜写笔记时，忽然发现自己在几个月前记下的疑问，如今已经有了自己的答案。这种"过去和现在的自己对话"的感觉，是自学路上最珍贵的体验。

不止代码

阅读技术论文

喜欢在 ArXiv 上浏览最新的 AI 论文，尤其关注 CV 和 NLP 领域的前沿进展。虽然很多论文读起来吃力，但每理解一个新 idea 都让人兴奋。

开源社区

关注 GitHub 上优秀的开源项目，学习优秀工程师的代码风格和架构设计。希望有一天自己的项目也能被别人 Star。

写作与表达

相信清晰的写作是清晰思考的外在表现。无论是技术笔记还是个人感悟，都力求用简洁、准确的语言传达复杂的思想。

持续学习

技术之外，也在关注产品设计、认知科学和个人效率提升方法。好的工程师不应该只埋头写代码，更要理解人与技术的关系。
